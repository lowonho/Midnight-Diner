# 커팅 에셋 관리 규칙

함께 제작하는 커팅 미니게임 에셋은 이 폴더에서 관리합니다.

- 재료별 하위 폴더를 사용합니다: `chicken`, `green-onion`, `kimchi`, `tofu`, `radish`, `fish-cake`
- 파일명은 `{재료}-{단계}.png` 형식입니다.
- `0`은 자르기 전 통재료이며 숫자가 올라갈수록 절단이 진행됩니다.
- 배경은 투명한 PNG로 저장합니다.
- 같은 재료의 모든 단계는 동일한 캔버스 크기와 위치를 유지합니다.
- 새로운 재료를 추가하면 `DAY_PREP_ASSET_PATHS`에도 경로를 등록합니다.
