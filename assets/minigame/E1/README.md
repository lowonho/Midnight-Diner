# E1 칼질 에셋 관리 규칙

E1 타이밍 칼질 미니게임의 재료와 칼 이미지는 모두 이 폴더에서 관리합니다.

- 파일명은 `{재료}-{단계}.png` 형식입니다.
- `0`은 자르기 전 통재료이며 숫자가 올라갈수록 절단이 진행됩니다.
- 배경은 투명한 PNG로 저장합니다.
- 같은 재료의 모든 단계는 동일한 캔버스 크기와 위치를 유지합니다.
- 새로운 재료나 단계를 추가하면 `DAY_PREP_ASSET_PATHS`에도 경로를 등록합니다.

대파는 `green-onion-0.png`부터 `green-onion-7.png`까지 입력 7회와 일대일로 대응합니다.
떡볶이 양배추는 `cabbage-0.png`부터 `cabbage-6.png`까지 입력 6회와 일대일로 대응합니다.
닭은 `chicken-0.png`부터 `chicken-11.png`까지 절단 11회와 일대일로 대응하며, 절단선마다 2회 입력합니다.
김치는 `kimchi-0.png`부터 `kimchi-9.png`까지 입력 9회와 일대일로 대응하며 두부김치와 김치전이 함께 사용합니다.
무는 `radish-0.png`부터 `radish-7.png`까지 입력 7회와 일대일로 대응합니다.

## 여백 없이 잘라 둡니다 (2026-08 ~)

재료 그림은 알파 여백을 남기지 않습니다. 도마 상자를 그림 비율(`--ing-ar`,
`css/day-prep-minigames.css`)로 만들어 통째로 보여주기 때문에, 여백이 있으면
그만큼 재료가 작게 보이고 재료 카드에서도 가운데로 쪼그라듭니다.

⚠️ 여백을 다시 자르거나 캔버스를 바꾸면 **두 곳을 같이 고쳐야** 합니다.
같은 칼자국이 다른 %로 옮겨가서, 안 고치면 절단선이 그림에서 밀립니다.

1. `css/day-prep-minigames.css` 의 `--ing-ar` (재료별 가로:세로)
2. `engine-e1-timing-cut.js` 의 `CUT_POSITION_PERCENTAGES` (절단선 X %)

확인은 `tools/e1-cut-screen-visual-smoke.html` 로 합니다 — 엔진 값을 그대로 써서
한 화면을 그리고, `data-measure` 의 `assetFillsBox` 가 `1` 이 아니면 비율이 어긋난 것,
`knifeEdgeOffPx` 가 `0` 이 아니면 칼날이 절단선에서 밀린 것입니다.

| 파일 | 쓰는 곳 |

| `prop_knife_chop_horizontal_ready_v2.png` | 두부·어묵 마지막 가로 썰기 (칼끝 왼쪽 · 날이 아래) |
| `fx_knife_board_impact_vertical_01~03.png` | 썰릴 때 터지는 연속 이펙트 (가로 썰기는 CSS 가 90도 돌려 씁니다) |

셋 다 납품본에서 알파 여백을 잘라낸 것입니다. 이펙트 3장만은 **낱장으로 자르면
안 됩니다** — 세 장의 알파 영역을 합친 공통 캔버스(424x1642)로 잘라야 1 → 2 → 3 이
같은 자리에서 번집니다. 그림 안에서 도마에 닿는 자리는 가로 50% · 세로 68.8% 이고,
CSS 가 그 점을 회전 중심으로 잡습니다.

### 칼 크기는 7종 모두 같습니다 (김치 썰기 기준)

| | 칼 크기 | 그림에서 날이 차지하는 비율 | 날 길이 |
| --- | --- | --- | --- |
| 세로 | 69 x 564 | 위 59.07% | 333 |
| 가로 | 564 x 64 | 왼 60.69% | 342 |

재료마다 크기를 맞추면 무는 과도, 양배추는 대검이 되어 같은 주방의 같은
칼로 안 보입니다. 그래서 크기를 고정하고, **날 한가운데를 재료 한가운데에**
겹칩니다. 손잡이는 도마 밖으로 나가도 됩니다 — 위에서 내려다본 도마라
손잡이가 화면 밖으로 빠지는 편이 자연스럽습니다.

날보다 큰 재료(양배추 427, 두부 600, 어묵 470)는 **써는 획이 그만큼 크게
지나가면서** 덮습니다.

| 획 | 이동 | 기울기 |
| --- | --- | --- |
| `cut-knife-chop-asset` (세로) | 위→아래 -84 ~ +96 | 들 때 왼쪽 -5도 → 닿을 때 0도 |
| `cut-knife-chop-side-asset` (가로) | 왼→오 -210 ~ +200 | 같음 |

기울기는 **날이 닿는 자리**를 축으로 돕니다(`transform-origin`). 가운데를
축으로 돌리면 날이 절단선에서 떨어집니다. 기울기는 내려오는 동안 유지하고
닿는 순간(44%)에 0 이 됩니다 — 안 그러면 가속 때문에 첫 프레임에 사라집니다.

⚠️ 세로 획을 -84 보다 더 들면 칼끝이 도마 위로 잘립니다. 칼 상자 위쪽은 늘
도마 안쪽 62.5 자리이고(날 한가운데를 재료 한가운데에 맞추므로) 도마 안쪽
여백이 22 뿐입니다.

⚠️ 서로 물려 있는 값이 셋입니다. 하나를 고치면 나머지도 봐야 합니다.

1. 칼 그림을 갈아 끼우면 위 "날 비율"을 다시 재서 CSS 의 `top`/`left`
   보정값(날 길이의 절반)을 고칩니다.
2. 재료를 키우면 획이 모자랄 수 있습니다 — 획 이동량을 같이 키웁니다.
3. 획을 키우면 그만큼 오래 걸리므로 `engine-e1-timing-cut.js` 의
   `pathRecoveryMs`(써는 순간 칼이 멈춰 있는 시간)도 같이 봐야 합니다.
   이 값보다 획이 길면 칼이 중간에 순간이동합니다.

셋 다 `tools/e1-cut-screen-visual-smoke.html` 의 `bladeCoversFood` 가 봅니다 —
`sweepUnder` · `sweepOver` 가 둘 다 0 이상이어야 획이 재료를 다 훑습니다.
세로 칼만 비율에 가로 1.22배를 섞어 씁니다(`aspect-ratio: 165 / 1351`) — 그림
그대로면 날이 바늘처럼 얇습니다. 눕힌 칼은 이미 두께가 제대로라 그대로 씁니다.

`knife.png` 는 이전 칼 그림입니다 — 지금은 어디에서도 쓰지 않습니다.
