# E13 냉장고 재료 찾기

24칸(3단 × 4|4)이 재료로 꽉 찬 냉장고에서 오늘 메뉴에 필요한 재료만 눌러 꺼내는
낮 준비 전 미니게임입니다. 제한시간·실패는 없고 걸린 시간만 잽니다.

게임 규칙은 `engine-e13-fridge-find.js`, 화면 연결과 재료 데이터는
`ingredient-select.js`에 있습니다.

## 이 폴더의 그림

- `fix_fridge_open_empty_lit_24slot.png` — 문이 열린 빈 냉장고 한 장(3215x2001).
  가운데 플레이 칸(824.2 x 613.2)에 `100% 100%`로 늘려 깝니다. 칸 자리는
  `css/ingredient-select.css`의 `.fridge-slots`가 **% 로** 잡으므로 늘려도 같이 따라옵니다.
  ⚠️ 그림을 새로 받으면 그 파일의 선반 안쪽을 다시 재서 `.fridge-slots`의
  top/right/bottom/left · 가운데 기둥 폭을 갱신해야 합니다.

## 재료 그림

냉장고 안 재료는 각 조리 미니게임의 실제 원화를 공유합니다(이 폴더에 중복 에셋을
만들지 않습니다). 아직 원화가 없는 재료(양파·계란·소시지·오징어·다시마·고등어·
옥수수·소고기·청경채·배추·느타리버섯·팽이버섯·단호박)는
`css/ingredient-select.css` 아래쪽의 **임시 CSS 도형**(`.ic-*`)으로 그립니다.
원화가 들어오면 `ingredient-select.js`의 `FRIDGE_EXTRAS` 항목에 `asset` 경로만
적어 주면 도형은 자동으로 안 쓰입니다.
