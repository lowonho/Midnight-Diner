# E13 냉장고 재료 찾기

24칸(3단 × 4|4)이 재료로 꽉 찬 냉장고에서 오늘 메뉴에 필요한 재료만 눌러 꺼내는
낮 준비 전 미니게임입니다. 제한시간·실패는 없고 걸린 시간만 잽니다.

게임 규칙은 `js/engine-e13-fridge-find.js`, 화면 연결과 재료 데이터는
`js/ingredient-select.js`에 있습니다.

## 냉장고

`fix_fridge_open_empty_lit_no_vertical_dividers.png` (3165x2033) 한 장을
가운데 플레이 칸(824.2 x 613.2)에 `100% 100%`로 늘려 깝니다. 칸 자리는
`css/ingredient-select.css`의 `.fridge-slots`가 **% 로** 잡으므로 늘려도 같이 따라옵니다.

**칸막이가 없는 그림이라 맞출 것은 선반 높이와 재료 사이 간격 둘뿐입니다.**
실측값(그림 크기 대비 %):

| | 값 |
|---|---|
| 안쪽 벽 x | 왼칸 10.71 ~ 48.21 ┃ 가운데 기둥 3.99 ┃ 오른칸 52.20 ~ 88.66 |
| 선반 y | 13.23 → 31.58 / 33.45 → 53.71 / 55.83 → 75.50 |

간격은 한쪽 칸을 넷으로 똑같이 나눠 만들고(왼칸 12.027% · 오른칸 11.693%),
재료 그림은 칸 폭의 86%만 써서 옆 재료와 붙지 않게 합니다.
그림을 새로 받으면 위 값을 다시 재세요 — 가로/세로 밝기 gradient 봉우리로 뽑으면 몇 초입니다.

> `fix_fridge_open_empty_lit_24slot.png`(칸막이 있는 옛 그림)은 이제 아무 데서도 안 씁니다.

## 냉기

`fx_cold_air_anim_01~05.png` 다섯 장이 한 바퀴 도는 연속 그림입니다.
냉장고 안에 2~3덩이가 아무 데나 떠서 천천히 흐릅니다(자리·크기·시작 박자는
`js/ingredient-select.js`의 `fridgeColdAirMarkup`이 판마다 새로 뿌립니다).

⚠️ **다섯 장의 캔버스가 제각각입니다**(351x178 · 426x236 · 452x295 · 559x429 · 514x316).
한 상자에 꽉 채워 깔면 장마다 다르게 늘어나 덩이가 들썩입니다. 가장 큰 04를 기준으로
각 장의 상대 크기를 `css/ingredient-select.css`의 `.fridge-cold-frame.frame-*`이 들고
있고, 다섯 장 모두 상자 가운데에 겹칩니다(01 → 04로 갈수록 부풀어 오릅니다).
새 장을 받으면 그 표도 같이 갱신하세요.

## 재료 그림

- 요리에 쓰는 재료는 각 조리 미니게임의 원화를 공유합니다(중복 에셋을 만들지 않습니다).
- 냉장고에서만 보이는 재료 13종(`food_*_ingredient.png`)은 이 폴더의 전용 원화입니다.
- **손질 전 모습만 씁니다.** 우리 조리 과정에서 이미 썰린 그림(E11 두부 5쪽·E11 썬 김치·
  E8 깍둑 닭 정육·E3 썬 모둠채소)은 넣지 않고, 통두부·통김치(E1)를 씁니다.
- **눕혀 그린 원화는 비스듬히 눕힙니다.** 가로:세로 2 이상이면 `js/ingredient-select.js`에서
  `long:true`를 주면 40~50도로 기울어 들어갑니다(무·대파·통김치·닭고기·멸치).
  기우는 방향은 `lean`이 정합니다 — 무·대파·멸치는 잎과 머리가 위로(`1`),
  김치는 밑동이 아래로(`-1`). 두부·양파처럼 **정면으로 놓여야 할 재료는 아예 안 돌립니다.**
- **크기는 실물 비례입니다.** `size`가 배율이고 1 = 두부 한 모쯤입니다(배추 1.35 … 새우 0.62).
  칸보다 커지면 옆·위로 넘치는데, 칸막이가 없어 오히려 자연스럽습니다.
