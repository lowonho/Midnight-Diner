# 심야식당 비주얼 웹게임 V4

## 실행 방법
1. 압축을 해제합니다.
2. `index.html`을 실행합니다.
3. 브라우저에서 로컬 이미지가 제한되면 VS Code의 Live Server로 폴더를 실행합니다.

## JavaScript 구성
- `game.js`: 공통 상태, 입력, 미니게임, UI 및 Canvas 렌더링
- `day.js`: 낮 준비 초기화, 재료 준비 및 목표 UI
- `night.js`: 밤 영업, 주문, 조리, 서빙 및 정산

## V4 수정 사항
- 타이틀 화면과 게임 화면을 완전히 분리했습니다.
- `게임 시작`을 누르기 전에는 주방 캔버스와 게임 UI가 표시되지 않습니다.
- 시작 버튼을 누르면 타이틀 화면이 사라지고 실제 주방 화면으로 전환됩니다.
- 낮과 밤 전용 주방 배경 이미지를 적용했습니다.
- 냉장고는 왼쪽 벽에, 나머지 조리 집기는 뒤쪽 벽을 따라 배치했습니다.
- 캐릭터의 이동 및 상호작용 범위를 새 작업대 구조에 맞췄습니다.
- 설정 화면의 일시정지 및 볼륨 조절 기능은 유지했습니다.

## 조작
- 이동: WASD / 방향키 / 모바일 조이스틱
- 상호작용: Space / ACTION 버튼
- 손님 선택: 숫자 1~4
- 설정 및 일시정지: Esc 또는 우측 상단 톱니바퀴
