# 심야식당 비주얼 웹게임 V4

## 실행 방법
1. 압축을 해제합니다.
2. `index.html`을 직접 열거나 VS Code의 Live Server로 실행합니다.
3. 배포 환경과 동일한 테스트가 필요할 때는 Live Server 사용을 권장합니다.

## JavaScript 구성
- `phaser.min.js`: Phaser 3.90 게임 엔진
- `game.js`: 공통 상태, 입력, 미니게임, UI 및 Phaser 렌더링 연결
- `day.js`: 낮 준비 초기화, 재료 준비 및 목표 UI
- `night.js`: 밤 영업, 주문, 조리, 서빙 및 정산
- `save.js`: 자동 저장, 저장 데이터 검증 및 복원
- `title.js`: 타이틀 화면, 새 게임·이어하기 및 화면 전환

## 하루의 흐름
- 낮 준비에는 제한 시간이 없습니다. 음식을 준비한 뒤 `영업준비 완료`를 누르면 밤으로 넘어갑니다.
- 인기도가 높을수록 밤에 방문하는 평균 손님 수가 증가합니다.
- 새 게임의 인기도는 0에서 시작합니다.
- 음식의 만족도와 목표 손님 처리율에 따라 정산 시 인기도가 변합니다.
- 밤에 남은 재고는 판매가의 30%만큼 손실 처리되어 보유금에서 차감됩니다.

## 저장 및 이어하기
- 게임은 약 5초마다, 조리 완료·서빙·낮/밤 전환·정산 시점에 자동 저장됩니다.
- 타이틀의 `이어하기`로 마지막으로 저장된 낮, 밤 또는 정산 상태를 복원할 수 있습니다.
- 미니게임 도중에는 저장하지 않고 직전 안전 지점부터 이어집니다.
- `새 게임`은 기존 저장 데이터 삭제 여부를 확인한 뒤 시작합니다.

## V4 수정 사항
- 타이틀 화면과 게임 화면을 완전히 분리했습니다.
- `새 게임` 또는 `이어하기`를 누르기 전에는 주방 캔버스와 게임 UI가 표시되지 않습니다.
- 시작 버튼을 누르면 타이틀 화면이 사라지고 실제 주방 화면으로 전환됩니다.
- 낮과 밤 전용 주방 배경 이미지를 적용했습니다.
- 냉장고는 왼쪽 벽에, 나머지 조리 집기는 뒤쪽 벽을 따라 배치했습니다.
- 캐릭터의 이동 및 상호작용 범위를 새 작업대 구조에 맞췄습니다.
- 설정 화면의 일시정지 및 볼륨 조절 기능은 유지했습니다.

## 조작
- 이동: WASD / 방향키 / 모바일 조이스틱
- 상호작용: Space / ACTION 버튼
- 손님 선택: 숫자 1~4
- 설정 및 일시정지: Esc 또는 우측 상단 톱니바퀴
